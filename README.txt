DHANUSH MOVVA - LOCAL PORTFOLIO

WINDOWS QUICK START
1. Extract this ZIP (right-click > Extract All).
2. Open the Dhanush-Portfolio folder.
3. Double-click Open-Portfolio.bat, or open index.html in Chrome or Edge.
4. Click Play my intro. Choose an available male narration voice if needed.

Keep the files together. Do not open index.html from inside the ZIP.
No npm install, build step, or API key is required.

OPTIONAL LOCAL WEB SERVER
If opening index.html directly causes an issue, open a terminal in this folder.
If Python is already installed, run:
  py -m http.server 8000 --bind 127.0.0.1
Then open http://127.0.0.1:8000 in your browser.
Press Ctrl+C in the terminal to stop the server.
If the py command is unavailable but python is installed, use python instead.

EDIT IN VS CODE
Open this entire folder in VS Code.
- index.html: page content, ID card, and section structure.
- style.css: layout, colors, and animation styling.
- intro.js: introduction script, voice selection, and audio controls.
- intro-scenes.js: diagrams synchronized to the introduction.
- script.js: skills, project case studies, and navigation.
- motion.js: card flip, scroll effects, and other motion.
- dhanush-intro-sprites.png: character animation frames.
- dhanush-profile-original.jpeg: original profile photo used on the ID card.
- Dhanush-Movva-Resume.pdf: downloadable resume.

VOICE AND ANIMATION
Narration is synthesized by the browser, not a recording or a cloned voice.
Available male voices vary by computer and browser. Some voices need internet.
The character uses a small set of generated frames; it is not a lip-synced video.
All page assets are included; LinkedIn and email links open external services.
The hosted site does not change when you edit this local copy.
