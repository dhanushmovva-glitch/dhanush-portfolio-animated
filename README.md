# Dhanush Movva — Animated Portfolio

Personal portfolio showcasing business intelligence, Microsoft Fabric, and Power Platform work.

## View the portfolio

https://dhanushmovva-glitch.github.io/dhanush-portfolio-animated/

## Run locally

Open `index.html` in a browser, or double-click `Open-Portfolio.bat` on Windows. No installation or build step is required.

Optional local server:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Then visit http://127.0.0.1:8000.

## Files

- `index.html`: page content and sections
- `style.css`: responsive layout and styling
- `script.js`: skill filters, project case studies, and navigation
- `motion.js`: profile card and scrolling animations
- `intro.js`: narration and playback controls
- `intro-scenes.js`: diagrams synchronized with narration

The introduction uses browser speech synthesis. Available voices depend on the browser and device. Project previews use illustrative data.

## Publishing updates

GitHub Pages publishes the root of the `main` branch. Commit and push changes to update the website.
